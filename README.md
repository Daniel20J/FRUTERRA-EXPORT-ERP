# FRUTERRA-EXPORT-ERP

Repositorio del proyecto FRUTERRA ERP (Documentación, Diagramas y Prototipo PWA).

## Estructura
- /docs — Documentos del proyecto (.md / .docx)
- /diagrams — PlantUML y draw.io
- /prototype — Vite + React + TypeScript + Tailwind + PWA prototype

## Cómo usar
1. Crear ramas: `docs/init-docs` y `feat/prototype-pwa` para trabajo en documentos y prototipo.  
2. Para el prototipo: abrir `prototype/`, ejecutar `npm install` y `npm run dev`.  
3. Convertir los .md en .docx con `pandoc` o copiando/pegando en Word.
